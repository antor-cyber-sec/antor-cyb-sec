# Day 1: How Computers and the Internet Work

## Main Parts of a Computer
- **CPU:** The "brain" of the computer. It performs calculations and runs instructions.
- **RAM:** Temporary memory. It holds the programs and data currently in use.
- **Storage (SSD/HDD):** Permanent memory. Files and software are saved here.
- **Operating System:** The software that connects the hardware with the user.

## Client and Server
- **Client:** The device that asks for information, such as a phone or laptop.
- **Server:** A computer that stores website data and stays online 24/7 to serve it.

## IP Address and DNS
- **IP Address:** The unique address of a device on a network.
- **DNS (Domain Name System):** Works like a phonebook. It converts a website name (e.g. google.com) into an IP address.

## What Happens When I Type google.com
1. The browser asks DNS for the IP address of google.com.
2. DNS replies with the IP address.
3. The browser sends a request to that server.
4. The server sends back a response containing the website data.
5. The browser displays the page.

## Commands I Practiced
- `ping google.com`: Measures how long a message takes to reach the server and come back.
- `nslookup google.com`: Asks DNS for the IP address of a domain.
- `tracert google.com`: Shows the path (hops) a message takes to reach the server.

## My Results
- Ping response time: 36 ms
- IP address of google.com: 142.251.43.78

## Key Takeaway
The internet is a constant exchange of requests and responses between clients and servers.
