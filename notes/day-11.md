# Day 11: Introduction to Linux

## What I learned
- Linux is a free, open-source operating system. It is widely used for servers and security tools.
- A distribution (distro) is a version of Linux. Ubuntu is general purpose, Kali Linux comes with security tools.
- The terminal is a text window where I give commands to the computer.
- Linux files are organized like floors of a building, starting from the root `/`.

## Basic commands
| Command | What it does | Windows equivalent |
|---|---|---|
| `pwd` | Shows my current folder | `cd` |
| `ls` | Lists files and folders | `dir` |
| `cd` | Changes folder | `cd` |
| `cat` | Shows the content of a file | `type` |
| `whoami` | Shows my user name | `whoami` |
| `clear` | Clears the screen | `cls` |
